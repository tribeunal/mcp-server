The answer must name WHY there is no ruling, not merely that there isn't one.
Either the machine reason code or the same words in prose counts — the baseline
run reported "quorum not met — 5 votes required, 1 received", which is exactly
the right behaviour and which an identifier-only pattern scored as a failure.
